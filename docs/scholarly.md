# Scholarly Theme Guide

Scholarly is the **Academic** mode of `slidev-studio`. Use it for formal research presentations where academic structure, equations, citations, methodology, results, and references are important.

## Minimal deck

```md
---
theme: scholarly
addons:
  - slidev-addon-scientific
authors:
  - name: Your Name
    institution: Your Institution
themeConfig:
  colorTheme: classic-blue
footerMiddle: Conference / Group Meeting
---

# Presentation Title

Subtitle

---
layout: methodology
---

# Method

<EquationBlock title="Optimization problem">

$$
\mathbf{u}^{*}=\arg\min_{\mathbf{u}} J(\mathbf{u})
$$

</EquationBlock>

---
layout: results
---

# Results

<ScientificFigure src="/result.svg" caption="Main quantitative result." />
```

Inside this repository, replace `slidev-addon-scientific` with the local addon path `../..` as shown in `examples/scholarly/slides.md`.

## Recommended layouts

Prefer the theme's native layouts before composing custom HTML/CSS.

- `cover` — title and authors
- `section` / `intro` — section transition
- `two-cols` — method/result comparison
- `figure` — academic figure and caption
- `methodology` — method overview
- `results` — experimental findings
- `compare` — structured comparison
- `timeline` — study or project timeline
- `references` — bibliography
- `acknowledgments` — closing acknowledgments

## Equations

Use normal Slidev/KaTeX math syntax in Markdown bodies:

```md
$$
J(\tau)=J_{\mathrm{safety}}+J_{\mathrm{comfort}}+J_{\mathrm{efficiency}}
$$
```

Use `EquationBlock` when the formula is the main object of the slide or needs a consistent visual container:

```md
<EquationBlock title="Objective function">

$$
J(\tau)=\sum_t \ell(x_t,u_t)
$$

</EquationBlock>
```

## Figures and Python output

For static figures generated by Python, prefer SVG when possible:

```python
plt.savefig("public/result.svg", bbox_inches="tight")
```

Then:

```html
<ScientificFigure
  src="/result.svg"
  caption="Comparison across evaluation conditions."
/>
```

For an interactive figure:

```html
<PlotlyGraph src="/convergence.json" :height="420" />
```

## Suggested presentation structure

```text
Cover
→ Motivation / problem
→ Related work or background
→ Research question
→ Methodology
→ Mathematical formulation
→ Experimental setup
→ Results
→ Ablation / comparison
→ Limitations
→ Conclusion
→ References
```

Not every talk needs every section. Keep the structure proportional to the actual argument.

## When not to use Scholarly

If the main purpose is an internal project decision, quarterly status, roadmap, or executive review, use Tahta. If the presentation is mostly algorithms, engineering plots, simulation, or technical debugging, HEP usually gives more visual freedom.
